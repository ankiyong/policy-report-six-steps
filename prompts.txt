2. 자료 수집·분석 채팅
============================================================

②-1에서 필요한 자료와 조사 순서를 정한 뒤 직접 자료를 검색·확인하고 첫 해석을 적습니다. 이어서 같은 AI 채팅에서 ②-2를 사용해 자료와 내 해석을 정리·비교·점검합니다.

[②-1 조사계획 수립 · 과정별 지침 포함]

보고서 주제·제목과 조사 질문 입력 → 프롬프트 생성·복사 → 같은 AI 채팅에서 웹 문서 검색 요청 · 찾은 원문은 직접 확인하고 분석합니다.

준비할 자료·정보
- 직접 작성: ①에서 정한 보고서 작성 주제와 제목, 확인할 질문, 조사 범위, 자료로 판단하려는 사항
- AI에 요청: 웹에서 실제 확인한 정부·공공기관·학술 문서와 원문 링크, 보고서 활용 이유·주의점 목록
- 진행 순서: AI가 찾은 문서의 원문과 활용 범위를 확인해 조사 대상을 정하고 직접 읽고 분석합니다.

[내가 입력할 내용]
- 보고서 작성 주제: [1단계에서 정한 주제]
- 보고서 제목: [1단계에서 정한 제목]
- 자료를 통해 확인하고 싶은 질문: [ ]
- 조사 범위: [기간·지역·대상]
- 자료를 활용해 판단하려는 사항: [ ]

[요청 사항]
1. 이 채팅의 1단계 결과와 내가 입력한 보고서 주제·제목, 질문을 바탕으로
   보고서의 근거로 사용할 수 있는 공신력 있는 공개 문서를 웹에서 실제로 찾아 줘.
2. 정부·공공기관의 공식 통계, 연구·평가보고서, 지침과
   학술기관·학술지의 논문 등 원문과 발행 주체를 확인할 수 있는 자료를 우선 찾아 줘.
   공식 게시 페이지나 원문을 열어 문서의 실제 존재와 주제 관련성을 확인해 줘.
3. 확인한 문서는 아래 항목으로 목록을 작성해 줘.
   - 검토 순서와 중요도: 필수 / 보완 / 참고
   - 정확한 문서명
   - 발행기관·작성자 및 발행 시점: 확인된 정보만 표시
   - 이 문서로 확인할 질문
   - 본 주제와 관련된 내용과 이 문서가 필요한 이유
   - 보고서에서 근거로 활용할 부분: 문제·개선 필요성 / 개선방안 / 실행 조건 등
   - 공식 문서 게시 페이지 또는 원문 PDF의 직접 링크
   - 실제 확인 범위: 원문 확인 / 공식 게시 정보만 확인
   - 자료의 적용 범위와 활용 시 주의점
4. 문제의 존재·원인·개선 필요성을 판단하는 데 필요한 정도,
   자료의 신뢰성·주제 적합성·최신성·원문 접근 가능성을 기준으로 우선순위를 정해 줘.
5. 확인한 문서 중 가장 먼저 읽을 자료를 최대 3개 고르고 선정 이유를 설명해 줘.
   실제로 확인한 문서가 적으면 확인한 수만 제시해 줘.
6. 내가 원문을 읽은 뒤 기록할 수 있도록 자료명, 출처 및 링크,
   내가 분석한 내용, 본 주제와의 관련성, 해석이 어려운 내용,
   자료 활용 판단과 이유로 구성한 간단한 기록 양식을 제시해 줘.

[작성 조건]
- 이 과정에서는 실제 웹 검색으로 근거 문서를 찾되,
  자료 전체의 분석이나 최종 채택 판단까지 나를 대신해 완료하지 마.
- '인수인계 메모'처럼 공개 원문을 찾기 어렵고 근거를 확인할 수 없는
  일반적인 내부 기록·자료 종류만 나열하지 마.
- 검색 결과 제목만 보고 문서를 확인했다고 하지 말고,
  공식 게시 정보와 직접 읽은 원문의 확인 범위를 구분해 줘.
- 목록의 링크는 기관 홈페이지나 검색 결과가 아닌 해당 문서의 공식 게시 페이지나 원문으로 연결해 줘.
- 실제 확인하지 않은 문서명·발행정보·수치·출처·링크를 만들지 마.
  존재나 원문 접근 여부가 미확인인 자료는 확인한 문서 목록에 섞지 말고,
  '검색 후보(미확인)'로 따로 두어 확인할 기관과 검색어를 안내해 줘.
- 웹 검색을 사용할 수 없으면 검색할 수 없다고 밝히고,
  실제 문서를 찾은 것처럼 쓰지 말고 확인할 기관·검색 경로·검색어를 제안해 줘.
- 최근 자료를 우선하되, 변화 추이가 필요하면 과거 자료도 비교 대상으로 제안해 줘.
- 공신력 있는 문서라도 조사 대상·시점·범위가 다른 내용을
  우리 기관의 문제나 개선 효과를 직접 입증하는 근거로 확대 해석하지 마.
- 제안한 우선순위는 AI의 검토안이며, 최종 조사 대상과 자료 채택은 내가 결정해.

============================================================

각 단계에서 AI 답변을 받은 뒤에는 아래 문구로 사용자의 결정을 명시합니다. 같은 채팅에서 결정을 반영한 단계 결과 요약을 확인하고 다음 단계로 이어갑니다.

[내 결정]
- 내가 선택·확정한 사항: [ ]
- 선택·확정한 이유: [ ]
- 수정하거나 제외할 사항: [ ]
- 보류·추가 확인할 사항: [ ]

이 결정을 반영해 ‘단계 결과 요약’을 갱신해 줘.
내가 확정하지 않은 사항은 검토안으로 유지해 줘.

교육용 예시
예를 들어 “핵심정보 요약표를 우선 검토하되, 기존 게시 양식의 수정 가능 여부는 확인 필요로 남긴다”고 입력하면, 방안 선택과 실행 조건의 확인 상태를 구분해 다음 단계로 이어갈 수 있습니다.
