            HOW TO USE
            이렇게 사용하세요.
            
    
            1. 먼저 내 생각을 적기
              작성 요령과 예시를 읽고 내 경험·판단을 먼저 적습니다. 새 입력은 최대 3개와 선택 항목 “그 외 기타 사항”입니다. 예시는 입력 방법이며 그대로 정답으로 옮길 필요가 없습니다.
            2. 같은 AI 채팅에서 1~9단계 이어가기
              프롬프트를 생성·복사해 같은 대화에 붙여 넣습니다. 공통 원칙과 단계별 점검 질문이 함께 들어갑니다. 새 채팅에서는 최신 기획·근거 기록과 원문을 함께 전달해야 합니다.
            3. 1단계는 경험, 2단계는 주제 선택
              관심 주제·선정 이유·직접 본 현상을 적으면 AI가 정리합니다. 2단계는 그 기록을 이어받으므로 다시 입력하지 않습니다. 주제안과 범위를 선택·수정하고 이유를 말한 뒤 명확한 주제명·설명을 남깁니다.
            4. 3단계 추천 뒤 4단계 직접 읽기
              추천 자료는 검토 전입니다. 원문을 열고 직접 읽은 위치·자기 요약·주장과 연결을 적습니다. AI와 대조한 뒤 채택·수정·보류와 이유를 정합니다. 자료마다 같은 프롬프트를 반복하며 실제 파일은 AI 채팅에 직접 첨부합니다.
            5. 5단계 문제·배경, 6단계 개선방안
              채택한 근거로 핵심 문제를 고릅니다. 개선 아이디어가 있으면 자신의 안을 포함해 비교하고, 없으면 첫 칸을 비워 5개를 추천받습니다. 기대하는 변화와 선택 기준은 먼저 적고, 선택·수정·조합은 직접 결정합니다.
            6. 7단계는 순서·역할·시기
              어떤 순서로 할지, 누가 무엇을 맡으면 좋을지, 언제 준비하고 시험할지 아는 만큼만 적습니다. 모두 공란이면 같은 개선방안의 추진계획 2안, 일부 공란이면 빈 부분만 추천받습니다. AI의 제안을 고른 뒤에도 실제 담당자 협의·승인은 별도로 확인합니다.
            7. 8단계 효과와 확인 방법
              무엇을 만들었는지와 대상에게 어떤 변화가 생겼는지를 구분합니다. 근거 없는 개선율을 정하지 않고 측정할 자료·시점·담당·한계를 검토합니다. 측정 업무를 추진계획에 연결하고 전체 점검 상태를 확인합니다.
            8. 9단계 초안 → 사람의 검토 → 최종안
              최신 기획·채택한 근거와 실제 양식을 AI 채팅에 제공합니다. 초안에 내 판단과 다른 내용, 근거 없는 수치·원인·담당·일정이 들어갔는지 읽고 수정할 내용과 이유를 적습니다. 실제 양식 파일의 표·쪽 나눔·분량·출처도 직접 확인합니다.
            9. 내 결정과 이유를 기록하기
              AI 답변을 읽고 “내 결정 기록”에서 선택·수정·조합·보류한 내용과 이유를 남깁니다. 이 문구를 같은 AI 채팅에 보내 기획 기록을 갱신합니다. AI가 추천했거나 프롬프트를 복사했다는 이유만으로 단계가 완료되는 것은 아닙니다.
            10. 스킬 추가는 선택 부록
              Claude에 hwpx-writer 스킬을 추가하는 기존 안내는 부록에 있습니다. 이름·설명·지침을 복사해 등록한 뒤 필요한 파일과 실제 사용 가능 범위를 확인합니다. 사이트가 스킬을 설치하거나 문서를 생성하지는 않습니다.
            내 결정 예시
            “대표 폴더 지정과 권장본 표시를 조합하겠습니다. 기존 자료를 활용해 작게 시작하고 싶기 때문입니다. 실제 권한·갱신 담당·작업시간은 확인 필요로 남깁니다.”
            점검 상태는 반영 / 추가 결정 필요 / 자료 확인 필요 / 해당 없음과 이유로 기록합니다. 기획에 반영했다는 것과 실제 원문 검증·기관 승인 완료는 다릅니다.
            입력은 현재 페이지 안에서만 유지되며 새로고침·닫기 시 초기화됩니다. 서버로 전송하거나 AI 답변을 직접 생성하지 않습니다. 다운로드는 입력 전 기본 템플릿입니다. 강사용 예시는 가상 A기관과 가상자료로 구성한 사전 작성 자료입니다.
