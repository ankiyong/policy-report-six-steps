# 정책보고서 작성 · 사람의 판단으로 진행하는 9단계

기존 카드와 좌우 입력창을 유지한 정적 GitHub Pages 강의 사이트입니다. 정규 수업은 9단계이며 Claude의 hwpx-writer 스킬 추가는 별도 선택 부록입니다.

- 사이트: https://ankiyong.github.io/policy-report-six-steps/
- 수강생: practice.html
- 강사용 수업·시연: instructor.html
- 강사용 최종 원고: practice.html?mode=instructor&process=body#step-9
- 선택 부록: practice.html#appendix-skill

## 수업 흐름 · 180분
도입 10분 → 1 문제의식 10분 → 2 주제 확정 10분 → 3 자료 탐색 10분 → 4 원문 확인·근거 기록 20분 → 5 핵심 문제·배경 15분 → 휴식 10분 → 6 개선방안 25분 → 7 추진계획 20분 → 8 기대효과 15분 → 9 초안·검토·최종안 30분 → 마무리 5분.

1~8단계는 사람의 생각·판단·선택을 AI가 정리하고 질문·비교·점검합니다. 9단계는 사람이 선택한 기획과 채택한 자료를 바탕으로 AI가 첨부 양식에 작성하며 사람이 검토합니다. 모든 프롬프트에 공통 원칙과 해당 단계의 자연어 점검 기준을 포함합니다.

## 입력·공란 처리
- 새 입력은 최대 3개 + 선택 항목 ‘그 외 기타 사항’입니다.
- 2단계는 이전 기록을 이어받으며 주제·대상·경험의 재입력란이 없습니다. 사람 선택 뒤 주제명·설명·포함/제외 범위를 기록합니다.
- 3단계는 원문을 우선해 최대 3개를 추천하고, 4단계에서 직접 읽기·자기 요약·주장과 연결·채택 판단을 수행합니다. 자료별로 같은 프롬프트를 반복합니다.
- 6단계 아이디어 칸은 선택 입력입니다. 있으면 자신의 안을 포함해 2~3개를 비교하고, 없으면 서로 다른 아이디어 5개를 추천받습니다.
- 7단계 순서·역할·시기 세 칸은 선택 입력입니다. 모두 공란이면 같은 개선방안의 추진계획 2안, 일부 공란이면 입력을 유지한 채 빈 부분의 선택지만 요청합니다.
- 추천안은 사람의 선택·수정·조합과 이유를 받은 뒤 반영하며, 실제 담당자 협의·승인·자원 확보와 구분합니다.
- 9단계에는 초안과 최종안의 두 과정이 있습니다. 실제 양식은 AI 채팅에 첨부합니다.

## 기록과 예시
같은 AI 채팅의 기획·근거 기록을 이어갑니다. 새 채팅에서는 공통 원칙·현재 프롬프트·최신 기록·확인한 원문을 전달합니다. 점검 상태는 반영 / 추가 결정 필요 / 자료 확인 필요 / 해당 없음과 이유로 구분합니다.

강사용 예시는 가상 A기관 신규 청년인턴의 첫 행사 안내문 자료 탐색·확인 개선입니다. G1~G3 원문은 3단계 예시에 직접 제공하는 짧은 가상자료입니다. 실제 공개 문서·기관 조사·효과 측정·승인 결과로 사용하지 않습니다. 6단계에는 아이디어 공란 5개 추천과 사용자의 두 대안 조합, 7단계에는 공란 2안 비교와 선택 후 실행계획이 이어집니다. 완성 예시는 사전에 작성한 수업 자료로 입력 수정에 따라 자동 변경되지 않습니다.

## 사용 범위
입력은 페이지 메모리에서만 유지됩니다. 새로고침·닫기 시 초기화되며 서버 전송·AI 호출·파일 업로드 기능은 없습니다. 생성·복사한 프롬프트를 별도 AI 채팅에서 사용합니다. 다운로드 TXT는 입력 전 템플릿이며 화면 문구와 일치합니다.

강사용 비밀번호는 공개 정적 사이트의 입장 구분 편의 기능입니다. 인증 파일·비밀번호·기존 원본 PDF는 이번 개편에서 변경하지 않습니다. 제공 PDF는 이전 단계 구성을 가진 참고자료로 구분합니다.

## 주요 파일
- assets/js/prompts.js: 9단계·공통·부록 프롬프트와 선택 입력 메타데이터
- assets/js/writing-guides.js: 작성 요령·예시·입력 도움말
- assets/js/instructor-data.js: 같은 가상 사례의 입력·응답·사람의 선택 기록
- assets/js/guide.js, prompt-builder.js: 화면·검증·생성·복사
- content-plan.json: 수업 구성·프롬프트·작성 기준
- prompts-student.txt, prompts.txt: 내려받는 기본 프롬프트
- instructor.html, assets/js/lecture.js: 최신 강사용 수업 흐름
- assets/js/skill-setup.js, hwpx-writer-instructions.md: 선택 부록 자료

## 실행·배포
빌드 없이 index.html을 엽니다. GitHub Pages는 master 브랜치 루트에서 배포합니다. 단계 직접 주소는 #step-1 ~ #step-9이며 부록은 #appendix-skill입니다. 과거 #step-7은 이제 추진계획을 의미합니다.
입력·공란 분기·단계 이동·내 결정 기록·자료/템플릿 다운로드·강사용 예시·부록·모바일·키보드 조작을 검증합니다.
