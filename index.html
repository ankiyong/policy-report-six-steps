내가 결정할 것

예를 들면

준비할 자료·정보

    첨부자료는 사용할 AI 채팅에 직접 올려주세요. 이전 채팅의 결과 요약은 아래 입력 항목에 붙여 넣습니다.

    01 · 내 정보 입력

    각 항목을 입력하세요. 아직 모르면 ‘확인 필요’, 해당하지 않으면 ‘해당 없음’을 적어주세요.

    입력 내용은 단계 이동 시 유지되며,
    페이지를 새로고침하거나 닫으면 초기화됩니다.

    프롬프트

    
                
    
              
    
            
    
          
    
        
    
        
    
      
    
    
    
      

  
    
    HOW TO USE
    이렇게 사용하세요.
    
    
      
      
    1. 공통 지침과 준비자료 확인하기
      공통 지침은 모든 ‘단계 프롬프트’ 끝에 자동으로 포함됩니다. 각 카드를 열고 ‘준비할 자료·정보’를 확인하세요.
      2. 
      
    2. 내 정보로 프롬프트 생성하기
      ‘단계 프롬프트’ 탭에서 내 생각·판단과 이전 단계의 결과 요약을 입력합니다. ‘프롬프트 생성’을 누르면 입력 내용과 공통 지침을 포함한 본문이 완성됩니다.
      3. 
      
    3. 단계별 AI 채팅에서 사용하기
      완성된 본문을 복사해 해당 단계의 AI 채팅에 붙여 넣고, 준비한 자료를 직접 첨부합니다. 입력 내용을 고쳤다면 다시 생성하세요.
      4. 
      
    4. AI 답변을 읽고 내 결정 기록하기
      같은 카드의 ‘내 결정 기록’ 탭에서 선택·확정한 사항과 이유, 수정·제외 사항, 보류·추가 확인 사항을 적습니다. 생성한 결정문을 그 단계의 AI 채팅에 붙여 넣어 ‘단계 결과 요약’을 갱신하세요.
      5. 
      
    5. 갱신한 결과 요약을 다음 채팅으로
      AI가 갱신한 요약을 복사해 다음 단계 입력 항목에 붙여 넣습니다. 채팅 이름만 적으면 다른 채팅을 확인하지 못할 수 있으므로, 필요한 결과 요약과 근거 자료를 함께 전달하세요.
      6. 
    
    
    
    내 결정 예시
    핵심정보 요약표를 우선 검토하되, 기존 게시 양식의 수정 가능 여부는 확인 필요로 남긴다.
    
    
    ‘단계 결과 요약’은 ① 내가 확정한 사항 ② 검토안·AI 제안 ③ 근거와 출처 ④ 미결 사항으로 구분합니다. 방안을 선택했다는 것과 그 효과·비용·실행 조건을 확인했다는 것은 구분해 기록하세요.
    
    
    입력은 각자의 현재 페이지 안에서만 유지됩니다. 새로고침하거나 페이지를 닫으면 초기화되므로 필요한 본문은 따로 복사해 두세요. 이 사이트는 입력 내용을 서버로 보내거나 AI 답변을 직접 생성하지 않습니다. ‘전체 프롬프트’ 다운로드는 입력 전 기본 템플릿입니다.
