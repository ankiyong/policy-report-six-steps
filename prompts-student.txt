# 부록. Claude에 hwpx-writer 스킬 추가 확인

현재 이 채팅에서 hwpx-writer 스킬을 실제로 사용할 수 있는지 확인해 줘.

1. 등록된 스킬을 불러올 수 있는지 확인해 줘. 지침을 채팅에 붙여 넣었다는 이유만으로 스킬이 설치되었다고 말하지 마.
2. 지침에서 참조하는 scripts·references·양식 중 실행에 필요한 파일이 있는지 확인해 줘. 설명문만 저장되어 파일이 없다면 누락된 파일과 영향을 받는 기능을 알려 줘. 파일이나 검사 결과를 임의로 만들어 내지 마.
3. 현재 Claude에서 가능한 문서 작성 작업과 사용할 수 없는 기능을 구분해 줘. Windows 한컴 COM이나 실제 한컴 페이지 렌더링을 사용할 수 없으면 그 한계를 명시해 줘.
4. 스킬과 필요한 실행 자원이 모두 준비되었다면, 제목은 '스킬 설치 확인', 본문은 '스킬 설치 확인용 문서입니다.'로 편집 가능한 작은 HWPX 테스트 파일을 만들어 줘. 표는 '점검 항목 / 값' 두 열과 '파일 형식 / HWPX' 한 행으로 작성해 줘. 실제 표 객체를 사용하고 기관명·날짜 등은 추가하지 마. 필요한 자원이 없다면 현재 환경에서 가능한 대체 방법을 먼저 알려 줘.
5. 파일을 실제 생성했다면 다운로드 링크와 수행한 검사 결과를 알려 줘. 파일 구조 검사와 실제 화면 배치 검증을 구분하고, 확인하지 못한 항목은 '미검증'으로 표시해 줘.
