이 파일은 입력 내용이 반영되지 않은 기본 템플릿입니다.
①·③~⑥의 단계 프롬프트에는 공통 문구가 이미 포함되어 있습니다.
②-1·②-2에는 과정별 지침이 포함되어 있으므로 공통 문구를 별도로 추가하지 않습니다.
모든 단계는 하나의 AI 채팅에서 이어서 진행합니다. 앞선 대화의 결과와 내가 확정한 결정을 활용합니다.
②-1 → 직접 자료 검색·원문 확인·첫 해석 → ②-2도 같은 AI 채팅에서 이어갑니다.
AI 답변을 검토한 뒤 같은 AI 채팅에 “내 결정”을 보내 단계 결과 요약을 갱신하고 다음 단계로 이어갑니다.

2. 자료 수집·분석 채팅
============================================================

②-1에서 필요한 자료와 조사 순서를 정한 뒤 직접 자료를 검색·확인하고 첫 해석을 적습니다. 이어서 같은 AI 채팅에서 ②-2를 사용해 자료와 내 해석을 정리·비교·점검합니다.

[②-1 조사계획 수립 · 과정별 지침 포함]

조사 질문·범위 입력 → 프롬프트 생성·복사 → 앞선 단계와 같은 채팅에서 조사계획 검토 · 실제 검색과 첫 해석은 직접 수행합니다.

준비할 자료·정보
- 이 채팅에서 이어서 활용: ①에서 정한 핵심 문제와 검토 범위
- 직접 작성: 확인할 질문, 조사 범위, 자료로 판단하려는 사항, 이미 확보한 자료, 조사 시간·제약
- 진행 순서: AI가 제안한 목록과 우선순위를 검토해 조사 대상을 결정하고 직접 자료를 찾습니다.

[내가 입력할 내용]

- 조사에 사용할 수 있는 시간과 제약: [없으면 ‘별도 제약 없음’]

[요청 사항]
1. 1단계 결과와 내 질문을 바탕으로 필요한 자료 목록을 작성해 줘.
2. 각 자료가 어떤 질문에 답하고, 어떤 판단에 필요한지 설명해 줘.
3. 다음 기준으로 조사 우선순위를 정해 줘.
   - 핵심 문제가 실제로 존재하는지 확인하는 데 필요한 정도
   - 원인과 개선 필요성을 판단하는 데 필요한 정도
   - 자료의 신뢰성과 확보 가능성
   - 이미 확보한 자료와의 중복 여부
4. 자료 목록을 아래 항목으로 표로 작성해 줘.
   - 조사 순서
   - 중요도: 필수 / 보완 / 참고
   - 확인할 질문
   - 필요한 자료와 구체적인 확인 항목
   - 이 자료가 필요한 이유
   - 찾아볼 기관·사이트 또는 내부 자료
   - 추천 검색어
   - 조사 시 주의점
5. 마지막에 가장 먼저 찾아볼 자료 3개와 선정 이유를 제시해 줘.
6. 내가 조사 후 자료 내용과 직접 해석한 생각을 기록할 수 있도록
   간단한 입력 양식도 제시해 줘.

[작성 조건]
- 이 과정에서는 실제 자료 검색·수집·분석을 진행하지 말고,
  내가 직접 조사할 수 있도록 조사계획을 작성해 줘.

- 자료의 존재나 확보 가능성을 확인하지 못했다면
  ‘확인 필요’로 표시해 줘.
- 실제로 확인하지 않은 자료명·수치·출처·링크를 만들지 마.
- 제안한 우선순위는 AI의 검토안이며, 최종 조사 대상은 내가 결정해.
