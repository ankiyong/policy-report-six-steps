1~6단계는 하나의 AI 채팅에서 이어서 진행합니다. 이전 결과 요약을 다시 입력하지 않습니다.

# 2-1. 조사계획 수립

[내가 입력할 내용]

- 자료를 활용해 판단하려는 사항: [ ]

[요청 사항]
1. 이 채팅의 1단계 결과와 내가 입력한 보고서 주제·제목, 질문을 바탕으로
   보고서의 근거로 사용할 수 있는 공신력 있는 공개 문서를 웹에서 실제로 찾아 줘.
2. 정부·공공기관의 공식 통계, 연구·평가보고서, 지침과
   학술기관·학술지의 논문 등 원문과 발행 주체를 확인할 수 있는 자료를 우선 찾아 줘.
   공식 게시 페이지나 원문을 열어 문서의 실제 존재와 주제 관련성을 확인해 줘.
3. 확인한 문서는 아래 항목으로 목록을 작성해 줘.
   - 검토 순서와 중요도: 필수 / 보완 / 참고
   - 정확한 문서명
   - 발행기관·작성자 및 발행 시점: 확인된 정보만 표시
   - 이 문서로 확인할 질문
   - 본 주제와 관련된 내용과 이 문서가 필요한 이유
   - 보고서에서 근거로 활용할 부분: 문제·개선 필요성 / 개선방안 / 실행 조건 등
   - 공식 문서 게시 페이지 또는 원문 PDF의 직접 링크
   - 실제 확인 범위: 원문 확인 / 공식 게시 정보만 확인
   - 자료의 적용 범위와 활용 시 주의점
4. 문제의 존재·원인·개선 필요성을 판단하는 데 필요한 정도,
   자료의 신뢰성·주제 적합성·최신성·원문 접근 가능성을 기준으로 우선순위를 정해 줘.
5. 확인한 문서 중 가장 먼저 읽을 자료를 최대 3개 고르고 선정 이유를 설명해 줘.
   실제로 확인한 문서가 적으면 확인한 수만 제시해 줘.
6. 내가 원문을 읽은 뒤 기록할 수 있도록 자료명, 출처 및 링크,
   내가 분석한 내용, 본 주제와의 관련성, 해석이 어려운 내용,
   자료 활용 판단과 이유로 구성한 간단한 기록 양식을 제시해 줘.

[작성 조건]
- 이 과정에서는 실제 웹 검색으로 근거 문서를 찾되,
  자료 전체의 분석이나 최종 채택 판단까지 나를 대신해 완료하지 마.
- '인수인계 메모'처럼 공개 원문을 찾기 어렵고 근거를 확인할 수 없는
  일반적인 내부 기록·자료 종류만 나열하지 마.
- 검색 결과 제목만 보고 문서를 확인했다고 하지 말고,
  공식 게시 정보와 직접 읽은 원문의 확인 범위를 구분해 줘.
- 목록의 링크는 기관 홈페이지나 검색 결과가 아닌 해당 문서의 공식 게시 페이지나 원문으로 연결해 줘.
- 실제 확인하지 않은 문서명·발행정보·수치·출처·링크를 만들지 마.
  존재나 원문 접근 여부가 미확인인 자료는 확인한 문서 목록에 섞지 말고,
  '검색 후보(미확인)'로 따로 두어 확인할 기관과 검색어를 안내해 줘.
- 웹 검색을 사용할 수 없으면 검색할 수 없다고 밝히고,
  실제 문서를 찾은 것처럼 쓰지 말고 확인할 기관·검색 경로·검색어를 제안해 줘.
- 최근 자료를 우선하되, 변화 추이가 필요하면 과거 자료도 비교 대상으로 제안해 줘.
- 공신력 있는 문서라도 조사 대상·시점·범위가 다른 내용을
  우리 기관의 문제나 개선 효과를 직접 입증하는 근거로 확대 해석하지 마.
- 제안한 우선순위는 AI의 검토안이며, 최종 조사 대상과 자료 채택은 내가 결정해.

첨부자료와 내가 입력한 생각·판단을 우선 활용해 줘.
부족한 판단은 최대 3개의 질문으로 확인하되,
현재 정보로 작성 가능한 부분은 먼저 진행해 줘.

이 채팅의 앞선 대화와 첨부자료를 바탕으로 이전 단계의 결과와 내가 확정한 결정을 이어서 활용해 줘.
확인할 수 없는 내용은 추정하지 말고 필요한 부분만 질문해 줘.

[요청 사항]

2. 내가 이 AI 채팅에 첨부한 원문을 직접 읽고 아래 정보를 파악해 줘.
   - 발행기관·작성자 및 발행 시점

   첨부 원문이 없으면 제공한 링크의 원문에 접근할 수 있는지 확인해 줘.
3. 아래 항목으로 분석표를 작성해 줘.
   - 자료명과 출처 및 링크
   - AI가 원문에서 확인한 발행기관·작성자·발행 시점
   - AI가 원문에서 확인한 핵심 사실·수치와 근거 위치
   - AI가 원문에서 확인한 기준 시점·지역·대상·단위
   - 내가 분석한 내용: 입력한 내용 유지
   - 내가 입력한 본 주제와의 관련성
   - AI의 점검 의견: 원문과의 일치 여부·논리·누락
   - 내가 판단한 채택 / 검토 중 / 제외 여부와 이유
4. 원문에서 확인 가능한 범위에서 통계의 정의·단위·조사 대상이
   서로 비교 가능한지 점검해 줘.
5. 내가 분석한 내용을 다음과 같이 구분해 줘.
   - 자료가 뒷받침하는 분석
   - 자료와 맞지 않거나 근거보다 넓게 해석한 부분
   - 현재 자료만으로 판단하기 어려운 부분
6. 서로 다른 자료의 내용이 충돌하면 차이와 가능한 이유를 정리하되,
   원인이 확인되지 않았다면 추정으로 표시해 줘.
7. 추가 조사가 필요하면 필요한 자료와 그 이유를 제안해 줘.
8. 다음 ‘개선방안 도출’ 단계에서 활용할 근거와
   아직 해결되지 않은 질문을 정리해 줘.

[작성 조건]
- 원문을 읽고 첫 분석을 적는 일은 내가 수행해.
  AI는 첨부 원문의 사실·발행정보 파악과 내 분석의 정리·비교·점검을 맡아 줘.
- 내가 분석한 내용을 임의로 바꾸거나 AI의 해석으로 대체하지 마.
- 수정이 필요하면 원래 분석을 남기고,

- 내 판단과 다른 검토 결과가 있으면 근거와 이유 설명
- 내 기준에 따른 추천 대안과 선택 이유 제시

[작성 조건]

# 5. 추진계획 수립

[진행 방식]
이 채팅의 4단계 실행 가능성 검토 결과와 내가 확정한 결정을 이어서 활용해 줘.
내가 입력한 생각과 실제 여건을 바탕으로 추진계획 초안을 함께 만들어 줘.

이전 결과를 다시 붙여 넣도록 요구하지 마.
앞선 결정을 그대로 사용할 항목은 ‘앞선 내용 유지’,
아직 정하지 못한 항목은 ‘미정’으로 입력할 수 있어.
미정인 부분은 필요한 확인 과업과 계획 초안을 제안해 줘.

[내가 입력할 내용]
- 내가 선택한 대안과 선택 이유: [앞선 선택 유지 또는 변경 내용·이유. 이번 적용 범위와 제외·보류할 사항도 작성]
- 내가 생각한 실행 순서·선행 업무: [먼저 해야 한다고 생각하는 일. 아직 생각하지 못했으면 ‘미정’]
- 시작·완료 목표와 중간 점검 시점: [확정 일정 / 희망 일정 / 미정 구분]
- 달성하려는 목표·완료 기준: [어떤 변화나 결과가 나타나면 완료라고 볼 것인지. 수치 목표는 미정이어도 됨]
- 주관·협력 역할의 첫 안: [확정된 담당 / 협의할 역할·후보 / 미정 구분]
- 확보된 예산·인력과 추가로 필요한 자원: [예산·투입 시간·도구·자료 등. 확보된 것과 추가 확인할 것을 구분]

[요청 사항]

1. 선택한 대안을 실행할 과업으로 나눠 줘.
- 내가 선택한 방안과 적용 범위를 먼저 확인해 줘.
- 방안을 실행하려면 무엇을 해야 하는지 세부 과업으로 나누고,
  각 과업의 선행 업무와 산출물을 연결해 줘.
- 내가 제시한 실행 순서를 먼저 반영하되,
  누락되거나 순서를 바꿀 필요가 있으면 이유와 수정안을 알려 줘.
- 4단계에서 남은 조건은 구체적인 확인 과업으로 바꿔 줘.
  무엇을, 어떤 역할이, 어떤 자료나 협의를 통해 확인할지 제안해 줘.
- 필요하면 준비·시범·본격 추진으로 구분해 줘.
  본격 추진이나 확대는 시범 점검 결과와 내 결정 이후로 배치해 줘.
- 아직 대안을 선택하지 않았다면 선택에 필요한 질문을 하고,
  선택 전에도 공통으로 필요한 준비 과업만 정리해 줘.

2. 일정과 완료 기준을 함께 제안해 줘.
- 전체 계획과 주요 과업의 시작·중간 점검·완료 시점을 연결해 줘.
- 각 단계에서 무엇을 달성해야 하는지,
  어떤 결과를 확인하면 다음 단계로 넘어갈 수 있는지 적어 줘.
- 완료 기준은 ‘검토 완료’, ‘협의 완료’라고만 쓰지 말고,
  확인해야 할 내용이나 남겨야 할 결과가 드러나게 작성해 줘.
- 산출물을 만들었다는 것과 실제 개선 효과가 확인됐다는 것을 구분해 줘.
- 날짜가 미정이면 선후 관계와 착수 조건을 먼저 제시해 줘.
  기간을 제안할 때는 산정에 사용한 정보와 가정을 밝히고
  ‘일정 제안’으로 표시해 줘.
- 일정 충돌과 지연 요인을 점검하고,
  대응 방안과 예비 기간이 필요한 구간을 제안해 줘.

3. 주관·협력 역할과 필요한 자원을 구체화해 줘.
- 과업마다 누가 주관하고 누구의 협력이 필요한지 연결해 줘.
- 작성·실행·검토·승인·갱신 중 필요한 책임을 구분해 줘.
- 실제 담당자가 정해지지 않았다면 필요한 역할을 제안하고,
  역할 지정이나 협의를 선행 과업에 넣어 줘.
- 필요한 예산·인력·투입 시간·도구·자료를 과업과 연결하고,
  확보된 자원과 추가 확인·확보할 자원을 구분해 줘.
- 기존 역할과 자원으로 수행할 수 있는지 먼저 검토해 줘.
- TF가 필요하다면 필요한 이유, 구성할 역할,
  의사결정·회의·결과 관리 등 운영 방식과 운영 기간을 제안해 줘.
  필요성이 확인되지 않으면 TF 구성을 전제로 하지 마.

4. 위 내용을 하나의 추진계획표로 정리해 줘.
- 단계·세부 과업
- 선행 업무·착수 조건
- 주관·협력 역할
- 시작·중간 점검·완료 시점
- 필요한 자원과 확보 상태
- 산출물
- 점검·완료 기준

미확정 담당·일정·자원·목표는 해당 항목에
‘제안’ 또는 ‘확인 필요’를 표시해 줘.

5. 계획표 아래에 실행 전 점검 결과를 짧게 정리해 줘.
- 누락·중복 과업과 순서 조정이 필요한 부분
- 주요 지연 요인, 추가 업무 부담과 대응 방안
- 가장 먼저 해야 할 준비 과업 최대 3개
- 계획을 확정하기 위해 내가 결정하거나 확인할 사항

[작성 조건]
- 4단계의 우선 검토안, AI 추천, 내가 최종 선택한 방안을 구분해 줘.
  AI의 추천을 내가 확정한 결정으로 바꾸지 마.
- ‘조건 충족 시 가능’ 또는 ‘추가 확인 필요’인 사항을
  승인·협의·자원 확보가 완료된 것으로 처리하지 마.
- ‘임의 작성’, ‘미정’, ‘모름’은 실제 확보된 조건으로 보지 마.
- 원문 위치·접근권한·갱신 책임처럼 앞선 단계에서 제시한
  선행 조건은 관련 과업의 착수 전에 확인하도록 배치해 줘.
- 기존 방식과 AI 보조 등 추가 기능의 실행 조건이 다르면 구분해 줘.
  추가 기능은 내가 포함하기로 선택한 범위에서만 계획하고,
  필요한 사용 승인·자료 범위·검증 책임을 확인 과업에 넣어 줘.
- 추가 기능의 조건이 미정이어도,
  그 기능 없이 진행할 수 있는 기본 준비 과업은 정리해 줘.
- 내 선택 범위를 넘어 새 시스템·조직·인력을 자동으로 추가하지 마.
- 기대효과와 완료 기준의 수치를 근거 없이 만들지 마.
  기준값이 없으면 먼저 무엇을 측정·확인할지 제안해 줘.

# 6-1. 개요 초안 작성

[진행 방식]

이 단계에서는 개요를 제안하고 내 확인을 받아 줘. 본문은 개요 확정 후 6-2에서 작성해 줘.

[내가 입력할 내용]

1. 앞선 단계의 확정한 판단, 선택한 개선방안, 추진계획과 근거를 확인하고,
   아직 미결인 내용과 AI 제안을 구분해 줘.
2. 아래 네 부분의 순서와 제목에 맞춰 보고서 개요 초안을 작성해 줘.

   - 개선방안: 선택한 방안의 변경 내용, 실행 방법과 타당성 근거
   - 추진계획: 세부 과업, 담당·협력 역할, 일정과 점검·완료 기준
   - 기대 효과: 어떤 변화가 왜 기대되는지, 근거와 성립 조건, 확인 방법
4. 문제 → 개선방안 → 실행 과업 → 기대 효과의 대응 관계를 점검해 줘.
   문제와 연결되지 않는 방안이나 근거 없는 효과는 따로 알려 줘.
   방안과 과업은 내가 확정한 우선순위나 추진 순서에 맞춰 배열해 줘.
5. 상세 수치·사례·근거 중 본문에 남길 내용과 각주·붙임으로 분리할 내용을 제안해 줘.
6. 개요 아래에 논리 연결·근거·누락·상충 사항과 내가 결정할 부분을 짧게 정리하고,
   이 개요를 확정할지, 수정할지 같은 채팅에서 확인해 줘.

[작성 조건]
- 이후 내가 변경·확정한 사항을 우선 반영하되, 해소되지 않은 충돌은 ‘확인 필요’로 표시해 줘.
- 기관 양식이 있으면 네 부분에 대응시켜 적용할 방법을 제안해 줘.
  필수 목차와 충돌하면 임의로 구조를 바꾸지 말고 조정안을 확인받아 줘.
- 내가 확정한 내용의 의미·주장 범위·불확실성을 유지해 줘.
- 미확정 예산·일정·담당·협의 결과를 사실처럼 쓰지 마.
- 기대 효과는 실행 전 예측이며 실제 효과가 검증된 것으로 쓰지 마.
  근거가 부족하면 ‘기대 효과(추정)’로 표시하고 효과 수치를 임의로 만들지 마.
- 새 주장을 추가하거나 분량을 채우기 위해 근거 없는 내용을 만들지 마.
- 내가 개요를 확정하기 전에는 ‘개요 초안’으로 표시하고 본문 초안 작성으로 넘어가지 마.
- 글씨체·편집용지·줄 수·페이지 배치는 실제 기관 양식에 적용한 뒤 확인할 사항으로 남겨 줘.

첨부자료와 내가 입력한 생각·판단을 우선 활용해 줘.
내 결정을 대신하지 말고, 부족한 판단은 최대 3개의 질문으로 확인해 줘.

확인된 사실 / 내가 확정한 사항 / AI의 제안·추정을 구분해 줘.
내가 선택한 방안도 효과·비용·실행 가능성까지 확인된 것은 아니야.
수치·출처를 임의로 만들지 말고, 미확인 내용은 ‘확인 필요’로 표시해 줘.

이 채팅의 앞선 대화와 첨부자료를 바탕으로 이전 단계의 결과와 내가 확정한 결정을 이어서 활용해 줘.
확인할 수 없는 내용은 추정하지 말고 필요한 부분만 질문해 줘.
자료가 부족해도 작성 가능한 부분은 진행해 줘.

답변 마지막에 ‘단계 결과 요약’을 작성해 줘.
① 내가 확정한 사항
② 검토안·AI 제안
③ 근거와 출처
④ 미결 사항

내가 확정하지 않은 내용은 확정 사항으로 표시하지 마.

# 6-2. 본문 초안 작성

[진행 방식]

앞선 대화에서 확인할 수 있는 개요나 이전 단계 결과를 다시 붙여 넣도록 요구하지 마.

[내가 입력할 내용]
- 6-1 개요 확정 여부와 수정 사항: [앞선 대화에서 확정 / 6-1 개요 확정 / 수정 후 확정 / 아직 미확정. 수정 시 바꿀 부분 명시]
- 항목별로 더할 내용·표현에 대한 내 생각: [추가 의견. 없으면 ‘없음’]

- 본문 분량·자료 기준일·출력 형식: [앞선 내용 유지 또는 변경 사항. 미정 항목 구분]

[요청 사항]
1. 먼저 개요 확정 여부를 확인해 줘.
   - 앞선 대화나 이번 입력에서 내가 확정한 개요만 본문 작성의 기준으로 사용해 줘.
   - ‘수정 후 확정’이라고 입력했고 수정 범위가 명확하면 그 내용으로 반영해 줘.
   - 아직 확정하지 않았거나 수정 지시가 모호하면 수정 개요와 필요한 확인 질문부터 제시해 줘.
     임의로 개요가 승인되었다고 판단하거나 본문 전체 작성으로 넘어가지 마.
2. 개요가 확정되었다면 다음 네 부분으로 본문 초안을 작성해 줘.
   1. 추진배경 및 문제점
   2. 개선방안
   3. 추진계획
   4. 기대 효과
   확정된 중제목·소제목과 순서를 따르고, 각 항목의 판단과 근거를 문장으로 연결해 줘.
3. 문제 → 개선방안 → 실행 과업 → 기대 효과의 연결을 확인해 줘.
   - 제기한 문제에 대응하는 방안과 구체적인 실행 방법·근거
   - 방안의 우선순위 또는 추진 순서
   - 주관·협력 역할, 일정, 단계별 목표와 완료 기준
   - 기대하는 변화의 근거, 성립 조건과 실제 확인할 방법
4. 개조식으로 간결하게 쓰고 항목별 설명은 가급적 2줄 이내로 다듬어 줘.
   의미를 줄이거나 불확실성을 삭제해 분량을 맞추지 마.
   상세 근거는 각주·붙임으로 분리하고 수치·사례에는 확인된 출처를 표시해 줘.
5. 제공된 기관 양식·작성 요령에 맞춰 글씨체·편집용지·항목 체계를 적용할 수 있게 정리해 줘.
   채팅 화면의 줄바꿈만으로 실제 문서의 줄 수·페이지 배치가 맞는다고 단정하지 마.

[작성 조건]
- 이후 내가 변경·확정한 사항을 우선 반영해 줘.
- 해소되지 않은 판단·근거·일정의 충돌은 ‘확인 필요’로 남겨 줘.
- 확정한 내용의 의미·주장 범위·불확실성을 유지해 줘.
- 미확정 예산·일정·담당·협의 결과를 사실처럼 쓰지 마.
- 법·예산·조직의 실행 조건이 확인된 범위와 남은 조건을 구분해 줘.
- 기대 효과를 이미 달성된 성과처럼 쓰지 마.
  검증되지 않은 효과는 ‘기대 효과(추정)’로 표시하고 근거 없는 수치를 추가하지 마.
- 분량을 채우기 위한 새로운 방안·사실·수치·출처를 만들지 마.
- 제공한 근거의 원문을 확인할 수 없으면 ‘원문 확인 필요’를 표시해 줘.

[본문과 별도로 제시]

- 사람이 최종 확인할 사항: 판단·수치·출처·승인·미결 조건 등
- 실제 기관 양식에서 확인할 사항: 글씨체·편집용지, 항목별 줄 수, 표·각주·붙임과 페이지 배치
- 개요가 미확정이면 본문 대신 수정 개요와 개요 확정에 필요한 확인 사항
