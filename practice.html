          프롬프트
          
                
          
                
          
              
          
            
          
          
          
        
          
        
          
      
          
    
          
            

  
    
          HOW TO USE
          이렇게 사용하세요.
          
    
            
      
          1. 작성 요령과 예시부터 확인하기
            단계 카드를 열면 ‘작성 요령’ 화면이 나옵니다. 원칙과 교육용 예시, 준비자료를 확인하고 ‘입력 시작하기’를 누르세요. 상단의 ‘입력·프롬프트’ 탭으로 바로 이동할 수도 있습니다.
            2. 
      
          2. 내 정보로 프롬프트 생성하기
            ‘입력·프롬프트’에서 이번 단계에 필요한 내 생각·판단을 입력합니다. ‘프롬프트 생성’을 누르면 공통 지침과 입력 내용을 반영한 본문이 완성됩니다. 작성 요령을 다시 보거나 다른 탭으로 이동해도 입력과 생성 결과는 유지됩니다.
            3. 
      
          3. 처음부터 끝까지 같은 AI 채팅에서 사용하기
            1단계부터 시작한 하나의 AI 채팅에 각 단계의 완성된 프롬프트를 순서대로 붙여 넣고, 필요한 자료를 직접 첨부합니다. 입력 내용을 고쳤다면 다시 생성하세요.
            4. 
      
          4. 2단계는 같은 채팅에서 두 과정으로
            ‘②-1 조사계획 수립’에 1단계에서 정한 보고서 주제·제목을 입력합니다. 생성한 프롬프트를 AI 채팅에 보내면 웹에서 실제 확인한 공신력 있는 문서와 링크를 추천받을 수 있습니다. 문서 원문을 읽고 직접 분석한 뒤 ‘②-2 조사·해석 결과 정리’에 출처·분석·채택 판단을 입력하세요. 발행기관·작성자·발행 시점은 AI가 첨부 원문에서 확인하도록 요청합니다. 실제 자료 파일은 AI 채팅에 직접 첨부하세요. ‘자료 추가’로 자료별 입력 묶음을 늘릴 수 있습니다.
            5. 
      
          5. AI 답변을 읽고 내 결정 기록하기
            같은 카드의 ‘내 결정 기록’ 탭에서 선택·확정한 사항과 이유, 수정·제외 사항, 보류·추가 확인 사항을 적습니다. 생성한 결정문을 진행 중인 AI 채팅에 붙여 넣어 ‘단계 결과 요약’을 갱신하세요.
            6. 
      
          6. 같은 채팅에서 다음 단계로 이어가기
            다음 단계 프롬프트도 진행 중인 채팅에 붙여 넣습니다. AI는 앞선 대화와 첨부자료, 내가 확정한 결정을 바탕으로 이어서 작업합니다. 대화에서 확인할 수 없는 내용은 필요한 부분만 질문하도록 안내합니다.
            7. 
    
          
    
          내 결정 예시
          핵심정보 요약표를 우선 검토하되, 기존 게시 양식의 수정 가능 여부는 확인 필요로 남긴다.
          
    
          ‘단계 결과 요약’은 ① 내가 확정한 사항 ② 검토안·AI 제안 ③ 근거와 출처 ④ 미결 사항으로 구분합니다. 방안을 선택했다는 것과 그 효과·비용·실행 조건을 확인했다는 것은 구분해 기록하세요.
          
    
          입력은 각자의 현재 페이지 안에서만 유지됩니다. 새로고침하거나 페이지를 닫으면 초기화되므로 필요한 본문은 따로 복사해 두세요. 이 사이트는 입력 내용을 서버로 보내거나 AI 답변을 직접 생성하지 않습니다. ‘전체 프롬프트’ 다운로드는 입력 전 기본 템플릿입니다.
