# 10-1. 핵심 내용 추출 (원문 36쪽)

첨부한 HWPX 보고서를 한 장의 정책 제안 포스터로 만들려고 해.
먼저 보고서를 읽고 다음 내용을 짧게 정리해 줘.
- 해결하려는 핵심 문제
- 문제를 뒷받침하는 주요 근거
- 보고서에서 제안한 개선방안
- 기대효과와 적용 조건
- 독자에게 검토하거나 결정해 달라고 요청할 사항
각 내용이 보고서의 어느 부분에 있는지 함께 표시해 줘.
보고서에 없는 내용은 추가하지 말고, 예상 효과와 확인된 성과를 구분해 줘.
파일을 읽을 수 없으면 필요한 본문이나 PDF 변환본을 요청해 줘.

# 10-2. 구성 정하기 (원문 37쪽)

정리한 보고서 내용을 바탕으로 정책 제안 포스터를 기획해 줘.
- 포스터를 볼 사람: [직접 입력]
- 가장 강조하고 싶은 제안: [직접 입력]
- 독자가 이해하거나 결정했으면 하는 사항: [직접 입력]
- 원하는 분위기: [예: 단정하고 신뢰감 있는 공공기관 스타일]
- 제목과 핵심 메시지를 3가지 안으로 제안하고, 각각 무엇을 강조하는지 설명해 줘.

================================================================

# 10-3. 이미지 생성 (원문 38쪽)

내가 확정한 제목·문구·구성으로 한 장의 정책 제안 포스터 이미지를 만들어 줘.
- 형태: A4 세로 비율
- 제목과 핵심 제안이 먼저 보이도록 정보의 크기와 위치를 조절
- 본문은 읽기 쉽게 배치하고 충분한 여백 확보
- 내용을 이해하는 데 필요한 간단한 아이콘과 삽화 활용
- ‘정책 제안’임을 명확하게 표시
- 근거의 출처는 하단에 읽을 수 있는 크기로 표시
확정한 문구·수치·조건을 임의로 바꾸거나 추가하지 마.
내용이 많아 가독성이 떨어지면, 먼저 줄일 문구를 제안하고 나에게 확인해 줘.

================================================================

# 10-4. 원문과 대조 (원문 39쪽)

완성된 포스터를 원본 보고서와 대조해 줘.
- 한글 오탈자와 잘못 표시된 숫자
- 원문과 달라진 주장이나 의미
- 빠져서 오해를 만들 수 있는 조건
- 예상 효과를 실제 성과처럼 표현한 부분
- 정책 제안을 확정·시행 중인 정책처럼 표현한 부분
- 출처 누락과 읽기 어려운 문구
문제가 있으면 ‘현재 표현 / 수정안 / 수정 이유’로 정리해 줘.
이미지에서 읽기 어려운 글자는 추측하지 말고 알려줘.
