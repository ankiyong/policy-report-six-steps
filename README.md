# 정책보고서부터 한 장 카드뉴스까지 · 10단계

사람이 생각하고 선택하며 AI를 보조 도구로 사용하는 정적 GitHub Pages 강의 사이트입니다. 기존 보고서 작성 1~9단계 뒤에 완성 보고서를 한 장 카드뉴스·포스터로 만드는 10단계를 추가했습니다. Claude의 hwpx-writer 스킬 추가는 별도 선택 부록입니다.

- 사이트: https://ankiyong.github.io/policy-report-six-steps/
- 수강생: practice.html
- 강사용 수업·시연: instructor.html
- 강사용 최종 원고: practice.html?mode=instructor&process=body#step-9
- 한 장 카드뉴스·포스터: practice.html#step-10
- 선택 부록: practice.html#appendix-skill

## 수업 흐름
기존 보고서 수업 180분: 도입 10분 → 1 문제의식 10분 → 2 주제 확정 10분 → 3 자료 탐색 10분 → 4 원문 확인·근거 기록 20분 → 5 핵심 문제·배경 15분 → 휴식 10분 → 6 개선방안 25분 → 7 추진계획 20분 → 8 기대효과 15분 → 9 초안·검토·최종안 30분 → 마무리 5분.

추가 10단계: 핵심 내용 추출 → 구성안 3개 비교·선택 → 이미지 생성 → 원문과 대조. 실습 시간은 강사가 별도로 배정합니다.

1~8단계는 사람의 생각·판단·선택을 AI가 정리하고 질문·비교·점검합니다. 9단계는 사람이 선택한 기획과 채택한 자료를 바탕으로 AI가 첨부 양식에 작성하며 사람이 검토합니다. 10단계는 최종보고서를 이어 쓰며, 제목·본문 문구·구성을 사람이 확정한 뒤 이미지를 생성하고 원문과 대조합니다.

## 입력·공란 처리
- 새 입력은 최대 3개 + 선택 항목 ‘그 외 기타 사항’입니다.
- 2단계는 이전 기록을 이어받으며 주제·대상·경험의 재입력란이 없습니다. 사람 선택 뒤 주제명·설명·포함/제외 범위를 기록합니다.
- 3단계는 원문을 우선해 최대 3개를 추천하고, 4단계에서 직접 읽기·자기 요약·주장과 연결·채택 판단을 수행합니다.
- 6단계 아이디어 칸은 선택 입력입니다. 있으면 자신의 안을 포함해 2~3개를 비교하고, 없으면 서로 다른 아이디어 5개를 추천받습니다.
- 7단계 순서·역할·시기 세 칸은 선택 입력입니다. 모두 공란이면 같은 개선방안의 추진계획 2안, 일부 공란이면 입력을 유지한 채 빈 부분의 선택지를 요청합니다.
- 추천안은 사람의 선택·수정·조합과 이유를 받은 뒤 반영하며, 실제 협의·승인·자원 확보와 구분합니다.
- 9단계에는 초안과 최종안의 두 과정이 있습니다. 실제 양식은 AI 채팅에 첨부합니다.
- 10단계 ‘구성 정하기’에는 볼 사람·강조할 제안·독자에게 바라는 이해나 결정의 세 항목을 입력합니다. 원하는 분위기는 기타 사항입니다. 추출·생성·대조는 앞선 기록을 이어 쓰고 기타 사항만 선택 입력합니다.

## PDF 원문과 실습용 프롬프트
- lecture.pdf: 사용자가 첨부한 18쪽 PDF 원본입니다. 강사용 페이지 첫 번째 슬라이드쇼는 표지·강사 소개를 포함한 18쪽 순서를 유지하며, 10번째 ‘보고서 작성 단계’와 11번째 ‘AI와 보고서를 쓸수록 기획이 더 중요하다’ 장표를 사용자가 지정한 9단계 이미지로 교체했습니다. 다운로드 PDF는 원본 그대로입니다.
- card-news-lecture.pdf: 두 번째 첨부 PDF의 33~39쪽만 추출한 7쪽 강의안입니다. 강사용 페이지에 별도 슬라이드쇼, 원문 보기·다운로드, 10단계 실습 연결을 제공합니다.
- 원문은 ‘한 장의 정책 제안 포스터’를 다룹니다. 여러 장 카드뉴스로 재구성하지 않았습니다.
- 10단계의 ‘PDF 원문’ 탭에서 36~39쪽의 프롬프트 4개를 각각 복사할 수 있습니다. 원문 위치를 표시하며, card-news-prompts.txt로 모두 내려받을 수 있습니다.
- ‘입력·프롬프트’ 탭의 실습용은 같은 채팅의 최종본 이어 쓰기·필수 입력 3개·사용자 선택·생성 기능 확인·수정 후 재확인을 보완한 버전입니다. 원문과 보완 사항을 구분해 표시합니다.

## 기록과 예시
같은 AI 채팅의 기획·근거 기록을 이어갑니다. 새 채팅에서는 현재 프롬프트·최신 기록·확인한 원문을 전달합니다. 보고서 단계의 점검 상태는 반영 / 추가 결정 필요 / 자료 확인 필요 / 해당 없음과 이유로 구분합니다.

강사용 예시는 가상 A기관 신규 청년인턴의 첫 행사 안내문 자료 탐색·확인 개선입니다. G1~G3는 수업용 가상자료이며 실제 기관 조사·효과 측정·승인 결과가 아닙니다. 10단계도 같은 가상 보고서를 사용합니다. 이미지 생성 예시는 배치 설계 원고이며 실제 PNG가 아닙니다. 원문 대조 예시는 의도적인 오류 문구를 검토하는 시연이며 실제 이미지 검수 완료를 뜻하지 않습니다. 완성 예시는 입력 수정에 따라 자동 변경되지 않습니다.

## 사용 범위
입력은 페이지 메모리에서만 유지됩니다. 새로고침·닫기 시 초기화되며 서버 전송·AI 호출·파일 업로드 기능은 없습니다. 생성·복사한 프롬프트를 별도 AI 채팅에서 사용하고 실제 보고서·포스터는 해당 채팅에 직접 첨부합니다. 이미지 생성은 사용하는 AI 도구의 기능에 따릅니다.

전체 다운로드 TXT는 입력 전 실습용 템플릿이며 화면 문구와 일치합니다. PDF 원문 TXT는 별도 파일입니다. 강사용 비밀번호는 공개 정적 사이트의 입장 구분 편의 기능입니다. 비밀번호는 유지하고 로그인 후 복귀 주소에 step-10을 허용했습니다.
